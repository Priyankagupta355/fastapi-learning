
# Request Body

## What is a Request Body?

A request body contains data sent by the client to the backend.

It is commonly used with:

- POST
- PUT
- PATCH

For example, when creating a new user, the frontend can send:

```json
{
    "name": "Priyanka",
    "age": 21,
    "email": "priyanka@example.com"
}
```
